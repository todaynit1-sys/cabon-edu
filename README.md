# 초록별 퀴즈 마을 — 지구 열 내리기 대작전

3D 마을을 걸어 다니며 AI 친구들과 탄소중립 퀴즈를 푸는 **어린이·학생 환경교육 웹앱**입니다.
아기 지구 '동글이'가 온실가스 담요 때문에 열이 나요. 마을 친구들의 퀴즈를 맞힐 때마다 회색 탄소 구름 '뭉게'가 나비로 바뀌고, 하늘이 맑아지고, 북극 얼음이 다시 커집니다.

AI는 **아이 기기의 브라우저 안에서 무료로** 돌아갑니다. 서버·API 키·비용이 없고, 아이가 쓴 글이 기기 밖으로 나가지 않습니다.
AI는 학년에 맞춰 문제를 다시 쓰거나 새로 내고, 틀리면 **아이가 고른 답에 맞춰 다시 설명**하고, 아기 북극곰 **얼음이와 대화**하고, **오늘 집에서 해 볼 실천 1가지**를 정해 줍니다. 다음에 들어오면 "어제 숙제 해 봤어?"라고 물어 게임 밖 실천까지 이어지게 합니다.

> 2026년 공공 AI 대전환 챌린지 세션1(자유주제 · 사회문제 해결 / 대국민 서비스 향상) 출품작 · 수도권대기환경청

## 0. 바로 실행하기

| 방법 | 절차 |
|---|---|
| 접속 주소 | (배포 주소 기재) |
| 내 PC에서 | 이 폴더에서 `node tools/serve.js` 실행 → 브라우저에서 `http://localhost:8080` |

- **AI 없이도 끝까지 플레이할 수 있습니다.** AI를 켜지 않으면 사람이 검수한 기본 문제은행(37문항)과 기본 설명으로 진행합니다.

### 무료 AI 켜기 (보호자·선생님)
1. 시작 화면 아래 **"✨ 무료 AI 켜기"** 또는 게임 중 오른쪽 위 **"AI 켜기"** 버튼을 누릅니다.
2. 모델을 고르고 **내려받고 켜기**를 누릅니다. 처음 한 번만 내려받아 브라우저에 저장합니다(와이파이 권장).
3. 다음에 들어오면 저장본으로 몇 초 안에 자동으로 켜집니다. 설정에서 **이 기기에서 지우기**로 언제든 지울 수 있습니다.

| 모델 | 내려받기 | 시험 결과 (2026.11, Intel Arc 내장 그래픽 노트북) |
|---|---|---|
| **Gemma 4 E2B** (구글, Apache-2.0) · 기본 | 약 2.8GB · 첫 켜기 약 1분 45초, 다음부터 약 8초 | 한국어가 자연스러움. 얼음이 대답·다시 설명이 정확하고 다정함 |
| Gemma 2 2B (구글) | 약 1.5GB | 아직 시험하지 않음 |
| Qwen 3.5 2B (Apache-2.0) | 약 1.1GB · 약 46초 | 가볍지만 한국어 문장이 자주 어색해 대부분 검증에서 걸러짐 |

- 최신 크롬·엣지의 **WebGPU**가 필요합니다. 지원하지 않는 브라우저에서는 "이 기기에서는 무료 AI를 쓸 수 없어요"라고 알리고 기본 문제로 진행합니다.
- 데이터 요금을 생각해 **자동으로 내려받지 않습니다.** 버튼을 눌렀을 때만 받습니다.

## 2. AI가 일하는 방식

### 모델 크기에 맞춰 일을 나눴습니다
실제 시험에서 2B급 작은 모델은 문제를 처음부터 새로 만들면 형식·사실이 자주 틀렸습니다(6개 중 2개만 통과, 그중에도 어색한 문제가 섞임). 그래서

- **작은 브라우저 모델 → "다시 쓰기"**: 사람이 검수한 문제의 **정답·보기는 그대로** 두고, 문장만 아이 학년과 생활 장면에 맞게 새로 씁니다.
- **큰 서버 모델(기관 공통기반·Ollama 등) → "새로 출제"**: 그 마을의 근거 카드로만 새 문제를 만듭니다.

```
[다시 쓰기]  검수된 문제 5개 ─▶ AI가 학년·생활 장면으로 다시 씀 (JSON 모양을 글자 단위로 강제)
                                   │
                                   ▼  [1차 자동 확인 · js/kidai.js verifyRewrite]
                                   · 원래 문제와 짝 맞추기(모델이 번호를 바꿔도 내용으로 매칭)
                                   · 뜻이 뒤집혔는지: 부정어 수, 반대말(켜/꺼, 같이/따로 …)
                                   · OX는 맞다/아니다로 답할 수 있는 문장인지, 3지선다는 질문인지
                                   · 원래 문제·근거와의 관련성, 학년별 길이, 아이 말투(~요), 겁주는 표현
                                   · 그대로 베꼈거나 이미 낸 문제와 같은지
                                   ▼  [2차 AI 교차 검토]  정답이 근거로 뒷받침되는가 · 결과가 빠진 문제는 내지 않음
                                   ▼
                    통과한 문제는 AI 문장으로, 못 한 문제는 사람이 검수한 원래 문장으로 출제

[새로 출제]  근거 카드 8장 ─▶ AI가 문제 + 근거 카드 번호 + 근거 구절 ─▶ 근거 구절이 카드에 실제로 있는지 대조
             ─▶ 형식·안전·중복 검사 ─▶ AI 교차 검토 ─▶ 통과분만, 모자라면 기본 문제은행에서 겹치지 않게 채움
```
- 브라우저 AI는 JSON 모양(스키마)을 주고 그 모양대로만 글자를 내게 강제해, 작은 모델도 형식을 틀리지 않습니다.
- 다시 설명 · 지구 숙제 · 얼음이 대답은 안전 점검 + 근거 카드와의 관련성 + 근거 번호 대조를 거치고, 떨어지면 기본 설명·기본 카드를 보여 줍니다.
- 시간 초과·형식 오류·AI 꺼짐이면 언제나 기본 자료로 바로 진행해 아이 화면이 멈추지 않습니다.

### 어린이 AI 안전장치 (js/safety.js)
- **개인정보 가리기**: 이름 · 전화번호 · 주소 · 아파트 동호수 · 학교 · 이메일 · 주민등록번호를 AI로 보내기 전에 ○○로 바꾸고 "비밀 지킴"을 알려 줍니다(브라우저 AI도 똑같이 적용).
- **입력 살피기**: 욕설·폭력·성적인 말은 AI로 보내지 않고 부드럽게 돌려 말합니다. 스스로를 해치려는 말에는 곁의 어른과 1388에 알리도록 안내합니다.
- **답변 점검**: 링크·전화번호·금지어를 지우고, 너무 긴 답은 자릅니다. 근거 카드에 없는 내용의 질문은 AI를 부르지 않고 "얼음이가 가진 카드에는 없는 내용"이라고 답합니다.
- 로그인 없음 · 대화 저장 안 함 · 1.5초 안에 다시 묻기 제한. 규칙 기반이라 완벽하지 않으니 운영 시 기관 금칙어 목록을 함께 쓰세요.

## 3. AI 연결 (모델 비종속)

앱은 `js/llm.js`의 `GreenLLM.chat()` 하나만 호출합니다. 연결 방식만 바꾸면 모델이 교체됩니다.

| 연결 방식 | 내용 |
|---|---|
| **webllm** (기본) | 브라우저 안 무료 AI. WebLLM 0.2.86 + WebGPU. Gemma 4 E2B · Gemma 2 2B · Qwen 3.5 2B |
| openai (OpenAI 호환) | 행정안전부 AI 공통기반(OpenAI 호환 게이트웨이) · 기관 vLLM · Ollama · LM Studio · OpenAI 등 |
| anthropic | Claude |
| claude-artifact | claude.ai에 게시한 공개 시연 페이지 안에서만 |

- 설정: 오른쪽 위 ⚙ → **브라우저 안 무료 AI 설정**, 또는 **다른 AI 서버에 연결하기**(주소·모델명·키).
- 기관 배포 기본값은 `js/config.js`에 적습니다. **API 키는 이 파일에 적지 마세요.**
- Google Gemini API는 약관상 18세 미만이 쓸 가능성이 높은 서비스에 쓸 수 없어 빠른 설정에서 뺐습니다.

## 4. 다른 주제로 바꿔 쓰기 (확산)

내용은 전부 `js/data.js` 한 파일에 있습니다. 화면·3D·AI 코드는 그대로 두고 이 파일만 바꾸면 다른 교육 주제가 됩니다.

| 대상 | 위치 |
|---|---|
| 마을 4곳 이름·친구·인사말 | `GQ_ZONES` |
| 마을 체험 순서·대사 | `GQ_MISSIONS` |
| 근거 카드 38장 (AI가 쓸 수 있는 유일한 사실) | `GQ_CARDS` |
| 기본 문제은행 37문항 (학년 수준 1~3, 다시 쓰기의 원본) | `GQ_BANK` |
| 기본 실천 카드 10장 | `GQ_ACTIONS` |

예: 물 절약 · 미세먼지 · 산불 예방 · 생활 안전 교육 자료를 근거 카드와 문제은행으로 넣으면 같은 마을에서 그 주제 퀴즈가 나옵니다.

## 6. 데이터 흐름 · 개인정보

- 로그인이 없고 이름·학교 같은 개인정보를 받지 않습니다. 진행 기록은 **이 기기 브라우저에만** 저장됩니다.
- **기본(브라우저 안 무료 AI)은 모든 AI 계산이 기기 안에서 이루어져 아이의 글이 어디에도 전송되지 않습니다.** 모델 파일만 처음 한 번 Hugging Face(mlc-ai)에서 내려받습니다.
- 다른 AI 서버를 연결하면 아이 질문(개인정보는 ○○로 가림) · 학년 · 근거 카드 · 문제 내용만 그 주소로 보냅니다.
- 수료증 이름은 인쇄용으로만 쓰고 어디에도 보내지 않습니다. 분석·추적 스크립트는 없습니다.

## 7. 알려진 제약

- 근거 카드·기본 문제는 공개 교육자료를 쉽게 고쳐 쓴 **체험용 예시**입니다. 실제 운영 전 환경교육 전문가·교사의 감수가 필요합니다.
- 브라우저 AI는 기기 성능을 탑니다. 시험한 노트북(Intel Arc 내장 그래픽)에서 Gemma 4 E2B로 문제 5개 다시 쓰기에 약 1분, 다시 설명에 약 25초가 걸렸습니다. 그래서 다음 마을 문제를 미리 만들어 둡니다.
- 작은 모델은 다시 쓰기를 소극적으로 해서(원래 문장을 거의 그대로 돌려줌) 한 번에 0~2개만 통과하기도 합니다. 통과 못 한 문제는 사람이 검수한 원래 문장으로 나오므로 내용은 항상 정확합니다.
- 브라우저 탭을 뒤로 숨기면 브라우저가 계산을 크게 늦춥니다. 앱을 앞에 띄워 두고 쓰세요.
- 읽어 주기는 브라우저 내장 음성을 써서 기기마다 목소리가 다릅니다.
