# AI 탄소중립 체험실 — 초록별 마을

**3D 마을에서 직접 체험하고, AI 선생님·AI 탄소 코치와 함께 "내 탄소"를 재고 줄이는 초등~고등 학생용 환경교육 서비스입니다.**
고등학생도 "내가 하루에 탄소를 얼마나 내보내는지"는 잘 모릅니다. 체험실은 행동 하나하나가 지구에 주는 효과를 숫자와 장면으로 보여 주고, AI가 학생 눈높이에 맞춰 설명·코칭합니다.

> 2026년 공공 AI 대전환 챌린지 세션1(자유주제 · 사회문제 해결 / 대국민 서비스 향상) 출품작 · 수도권대기환경청

| AI 기능 | 학생이 겪는 장면 | 검증 |
|---|---|---|

- 메이커의 AI는 **담당자가 고른 모델**에 연결합니다(3장). AI 없이 보여 주려면 **🎞️ 기록 재생**(저장된 생성 기록을 그대로 다시 재생)을 씁니다.

### 5분 시연 순서
1. `maker.html` → **샘플: 물 절약** 버튼 → 학년 수준·옵션 확인 → **✨ AI로 체험관 만들기** (클라우드 모델 2~4분).
2. 단계표에서 호출마다 **통과/요청/걸러짐**이 올라오고, 걸러진 항목은 이유와 함께 쌓입니다.
3. 검토 탭(설계 · 근거 카드 · 체험 · 문제 · 수업 · 실천 · 걸러진 항목)에서 고치고 **검토 완료** → **발행**.
4. **💾 이 기기에 저장하고 체험관 열기** → 새 주제의 3D 마을이 바로 열립니다. **🔗 링크 복사**는 팩 전체가 링크에 압축돼 담겨 다른 기기에서도 열립니다.
5. 같은 메이커에 다른 자료(예: 산불 예방)를 붙여 넣어 **현장에서 즉석 생성**할 수 있습니다.

## 1. 체험실 (학생용)

### 시작 화면
- **나는 지금**: 초등 저학년 · 초등 고학년 · 중학생 · 고등학생 — 문제와 수업의 눈높이(수준 1~4)가 바뀝니다. 고등학생도 "탄소가 얼마인지"는 잘 모르기에, 위 수준일수록 **수치와 원리**(1kWh = CO₂ 약 0.45kg, 냉방 1℃ = 7%, 나무 한 그루 = 6.6kg/년 …)가 들어갑니다.
- **내 캐릭터**: 추천 조합 8종(꼬마 탐험가 · 초등 축구왕 · 중학생 교복 · 고등학생 후드 …)에서 고르거나 **✏️ 직접 꾸미기** — 나이(꼬마·초등·중고등) · 성별 · 피부 6 · 눈 5 · 입 5 · 볼 3 · 머리 모양 9 · 머리 색 8 · 윗옷 6(교복·셔츠·후드 …) · 윗옷 색 12 · 아래옷 3 · 아래옷 색 8 · 소품 6(안경·헤드폰·책가방 …). 고른 모습은 3D 캐릭터에 바로 반영됩니다.

### 마을 체험 4종 (팩의 템플릿)
친구에게 가서 **체험하기**를 고르면 노란 화살표가 할 일을 알려 주고, 직접 해 볼 때마다 친구가 이유를 말해 줍니다.

| 템플릿 | 기본 체험관의 예 | 직접 하는 일 |
|---|---|---|
| `switch` 바로잡기 | 💡 반짝 에너지 집 · 불 끄기 순찰 | 전등·TV 끄기, 충전기 뽑기, 에어컨 26℃ 맞추기(고르기), 냉장고 문 닫기 |
| `sort` 줍고 분류하기 | ♻️ 뚝딱 재활용 공장 · 분리배출 대작전 | 떨어진 신문지·우유팩·페트병·캔·유리병을 주워 알맞은 칸에 넣기 |
| `plant` 심고 가꾸기 | 🌳 쑥쑥 숲 · 나무 심기 | 빈 흙더미 5곳에 묘목 심기 → 나무가 자라고 탄소 구름이 사라짐 |
| `ride` 타고 가기 | 🚲 씽씽 등굣길 · 자전거 등교 | 자전거를 타고 체크포인트 고리를 지나 초록 학교까지 |

### 🌍 "그래서 지구는?" — 실천이 지구를 어떻게 바꾸는지 보여 주기
- 체험 하나를 마칠 때마다 **효과 사슬**(예: ⚡ 전기를 아껴요 → 🏭 발전소가 연료를 덜 태워요 → 🌡️ 온실가스 ↓ 지구 열 ↓)과 **효과 문장**(예: "꽂아 둔 플러그만 뽑아도 집 전기의 약 6%를 아낄 수 있어요")이 뜨고, 지구 열 온도계가 **−4%**처럼 눈에 보이게 내려가며 걱정 구름이 사라집니다.
- 광장의 동글이와 마지막 화면에는 **📊 네 실천이 만든 변화** 보고서(실천 수 · 사라진 구름 · 지구 열 100%→n% · 마을별 효과 사슬)가 나옵니다.
- 효과 사슬·효과 문장은 팩에 담긴 글입니다(메이커가 근거 카드로 만들고 담당자가 고칩니다).

### 📚 배움터 (모두 팩에서 · 실시간 AI 없음)
| 기능 | 내용 |
|---|---|
| 배우기 | 주제(근거 카드)를 고르면 "이게 뭐야? → 이런 장면 → 오늘 해 볼 일" 3장 수업 + 확인 문제. 메이커가 학년별 수업을 만들어 두었으면 그 글을, 아니면 근거 카드 문장을 씁니다 |
| 문제 풀기 | 마을별 5문제(학년 수준에 맞춰 고름, OX·3지선다). 틀리면 **고른 답에 맞춘 다시 설명**(메이커에서 미리 생성·승인) 또는 힌트+해설, 비슷한 문제 한 번 더. 모든 문제에 **📄 근거 보기** |
| 마스코트에게 묻기 | 질문과 가까운 근거 카드를 찾아(BM25) 그 카드로만 대답. 이름·전화·주소·학교는 ○○로 가리고 알려 줌. 저장·전송 없음 |

### 재미 요소
마을 놀이 4종(30초, 별 1~3개) · 반짝 씨앗 12개(주울 때마다 상식 한 줄) · 별로 열리는 모자(새싹 머리띠 → 북극곰 귀 → 꽃 화관 → 아기 지구 모자 → 별 왕관) · 마스코트와 춤추기·쓰다듬기 · 📸 사진 · 점프 · 배경음악 · 수료증 인쇄 · 오늘의 숙제(다음 접속 때 "해 봤어?" → 실천 새싹 🌱).

## 2. 메이커 (담당자용)

### 흐름
```
1 자료 넣기 ──▶ 2 AI 생성 (단계마다 검증) ──▶ 3 검토·승인 (모든 글 수정 가능) ──▶ 4 발행
  교육자료 본문                                        탭마다 "검토 완료"                    이 기기 저장 · 링크(QR) · JSON
  학년 수준 1~4                                        걸러진 항목 + 이유 보기                 → 체험관이 바로 열림
```

### 생성 단계와 검증 (js/gen.js)
| 단계 | AI가 만드는 것 | 통과 조건 (자동) |
|---|---|---|
| A. 근거 카드 | 자료에서 사실 1개 = 카드 1장(제목·본문·검색 낱말·원문 구절) | **원문 구절이 자료에 실제로 있는지 대조**, 안전·겁주는 표현, 중복 |
| B. 마을·친구 설계 | 마을 4곳(템플릿 4종 각 1개)·친구·마스코트·광장 대사·카드 배정 | 템플릿 중복 금지, 동물 중복 금지, 안전 |
| C. 체험 미션 | 할 일 4~6개(이름·버튼 글·해 본 뒤 대사·**효과 문장**)·**효과 사슬 3단계**·분류 칸·탈것 | 대사·효과의 근거 카드 번호와 구절 대조, 길이, 안전 |
| D. 학년별 문제 | 수준마다 마을당 n문제(OX·3지선다·해설·힌트·근거 구절) | 근거 구절 대조, 관련성, OX 문장 꼴, 보기 3개·정답 하나, 길이(수준별), "~요" 말투, 안전, 중복 |
| D-2. AI 교차 검토 | 다른 호출이 "정답이 근거로 뒷받침되는가 · 정답이 하나뿐인가 · 안전한가" 판정 | 아니면 탈락 |
| E. 오답별 다시 설명 | 오답마다 "그렇게 생각할 수도 있어" + 근거로 2문장 | 근거 관련성, 안전 |
| F. 학년별 수업 | 카드마다 "이게 뭐야 · 이런 장면 · 오늘 해 볼 일" | 근거 관련성, 안전, "보호자와 함께" |
| G. 실천 카드 | 집에서 할 작은 실천 + 이유 | 근거 카드 번호, 안전 |

- 걸러진 항목은 **무엇이 · 왜** 걸러졌는지 그대로 보여 줍니다(심사·감수 근거). 모자라면 근거 카드로 채우고 "확인 필요"로 표시합니다.
- 생성된 팩은 `meta.approved = false`로 시작하고, 모든 탭을 검토 완료해야 승인 표시가 붙습니다(검토 안 한 탭이 있으면 발행 전에 확인을 묻습니다).
- **🎞️ 생성 기록 저장/재생**: 모든 AI 호출의 입력·출력·소요 시간을 JSON으로 남기고, 재생하면 AI를 부르지 않고 같은 검증 과정을 그대로 다시 보여 줍니다.

| webllm | 브라우저 안 모델(WebGPU · Gemma 4 E2B 등). 담당자 PC에서 외부 전송 없이 생성할 수 있으나 느리고 많이 걸러짐 |
| claude-artifact | claude.ai에 게시한 시연 페이지 안에서만 |

- 처음 **✨ AI로 체험관 만들기**를 누르면 키 넣는 창이 열립니다(Gemini가 기본). 키는 담당자 브라우저에만 저장되며("이 기기에 키 저장"을 끄면 창을 닫을 때 지워짐) **저장소·설정 파일에는 넣지 않습니다.**
- 메이커를 쓰는 사람은 담당자(성인)이므로 Gemini API를 써도 됩니다. 학생 체험관은 어떤 AI도 부르지 않으므로 약관 문제가 없습니다.
- 같은 자료를 두 모델로 생성해 **걸러진 비율**을 비교할 수 있습니다(기록 저장 → 걸러진 항목 탭).

## 6. 안전 · 개인정보
- 체험관: 로그인 없음, 이름·학교 같은 개인정보를 받지 않음, 진행 기록은 이 기기 브라우저에만 저장. **AI 호출이 없으므로 학생의 글이 어디로도 나가지 않습니다.**
- 묻기: 질문 속 이름·전화·주소·동호수·학교·이메일·주민번호를 ○○로 가리고 알려 줌(`js/safety.js`). 욕설·위험 표현은 부드럽게 돌려 말하고, 스스로를 해치려는 말에는 곁의 어른과 1388 안내.
- 메이커: 개인정보 없는 공개 교육자료만 넣도록 안내. 생성 글은 모두 담당자 검토 뒤에만 발행.

## 8. 알려진 제약
- 근거 카드·문제·효과 문장은 공개 교육자료를 쉽게 고쳐 쓴 **체험용 예시**이며, 실제 운영 전 환경교육 전문가·교사의 감수가 필요합니다.
- 생성 품질은 모델을 탑니다. 2B급 브라우저 모델은 형식은 지키지만 많이 걸러지고 느립니다. 기관 공통기반·클라우드 모델을 권장합니다.
- 3D 체험관은 WebGL이 되는 기기에서 열립니다. 브라우저 탭을 뒤로 숨기면 움직임이 멈출 수 있습니다.
- 읽어 주기는 브라우저 내장 음성을 써서 기기마다 목소리가 다릅니다.
