# 초록별 퀴즈 마을 — 지구 열 내리기 대작전

3D 마을을 걸어 다니며 AI 친구들과 탄소중립 퀴즈를 푸는 **어린이 환경교육 웹앱**입니다.
아기 지구 '동글이'가 온실가스 담요 때문에 열이 나요. 마을 친구들의 퀴즈를 맞힐 때마다 회색 탄소 구름 '뭉게'가 나비로 바뀌고, 하늘이 맑아지고, 북극 얼음이 다시 커집니다.

AI는 아이 학년에 맞춰 **근거 카드로만 새 문제를 내고**, 틀리면 **아이가 고른 답에 맞춰 다시 설명**하고, 아기 북극곰 **얼음이와 대화**하고, **오늘 집에서 해 볼 실천 1가지**를 정해 줍니다. 다음에 들어오면 "어제 숙제 해 봤어?"라고 물어 게임 밖 실천까지 이어지게 합니다.

> 2026년 공공 AI 대전환 챌린지 세션1(자유주제 · 사회문제 해결 / 대국민 서비스 향상) 출품작 · 수도권대기환경청

## 0. 바로 실행하기

| 방법 | 절차 |
|---|---|
| 접속 주소 | (배포 주소 기재) |
| 내 PC에서 (권장) | 이 폴더에서 `node tools/serve.js` 실행 → 브라우저에서 `http://localhost:8080` |
| 다른 정적 서버 | `npx serve .` 또는 `python -m http.server 8080` 등 아무 정적 파일 서버 |

- 권장 환경: Windows 10/11 · macOS · 크롬북, Chrome/Edge 최신판. 태블릿·휴대폰 브라우저도 지원합니다(화면을 누르면 걸어가요).
- 3D 엔진(three.js)과 글꼴은 CDN에서 받으므로 **인터넷 연결이 필요**합니다.
- `index.html` 파일을 더블클릭해서 여는 방식은 브라우저 보안 설정에 따라 동작하지 않을 수 있어 로컬 서버로 여는 것을 권장합니다.
- **AI 없이도 끝까지 플레이할 수 있습니다.** AI를 연결하지 않았거나 모델 서버가 꺼져 있으면 사람이 검수한 기본 문제은행(37문항)과 기본 설명으로 진행합니다.

## 1. 주요 기능

| 기능 | 내용 |
|---|---|
| 3D 퀴즈 마을 | 광장(아기 지구 · 지구 열 온도계)과 4개 마을: 반짝 에너지 집 · 뚝딱 재활용 공장 · 쑥쑥 숲 · 씽씽 등굣길 |
| **AI 맞춤 출제** | 학년(유치원~6학년)에 맞춰 그 마을의 근거 카드로만 새 문제 5개를 만듭니다 → 1차 자동 근거 대조 → 2차 AI 교차 검토 → 통과한 문제만 출제 |
| **AI 다시 설명** | 틀린 아이가 고른 답을 먼저 인정하고, 쉬운 비유로 왜 그런지 다시 설명합니다 |
| **비슷한 문제 한 번 더** | 같은 근거 카드로 상황만 바꾼 문제를 AI가 만들어 바로 다시 도전합니다 |
| **얼음이에게 묻기** | 질문과 가까운 근거 카드를 먼저 찾고(BM25 검색), 그 카드로만 대답합니다. 근거 카드를 눌러 원문을 볼 수 있어요 |
| **오늘의 지구 숙제** | 사는 곳 · 계절 · 재미있었던 마을에 맞는 실천 1가지를 정합니다. 다음 접속 때 "해 봤어?" → 실천 새싹 🌱 |
| 근거 보기 | 모든 문제에 "어디서 나온 말이야?" 버튼 — 근거 카드, AI가 짚은 근거 문장, 통과한 검증 단계를 보여 줍니다 |
| 읽어 주기 | 문제·해설·대답을 소리 내어 읽어 줍니다(글을 잘 못 읽는 아이도 끝까지) |
| 수료증 · 숙제 카드 인쇄 | 이름은 기기 안에서만 쓰고 어디에도 보내지 않습니다 |
| AI 활동 기록 | 설정 → AI 기록 보기: 몇 문제를 요청해서 몇 개가 통과했고, 어떤 문제가 왜 걸러졌는지 확인 |

## 2. AI가 일하는 방식

### 맞춤 출제 — 생성과 검증을 나눴습니다
```
근거 카드(그 마을 8장)  ──▶  AI가 문제 7개 생성 (근거 카드 번호 + 근거 문장을 글자 그대로 함께 적게 함)
                              │
                              ▼
               [1차 자동 대조 · js/kidai.js verifyItem]
               · 근거 카드 번호가 그 마을 카드인가
               · 근거 문장이 카드에 실제로 있는가 (지어낸 문장 차단)
               · 문제와 근거 카드의 관련성
               · OX/3지선다 형식, 정답 번호, 보기 중복
               · 학년별 문장 길이, 겁주는 표현·금지어, 이미 낸 문제와 중복
                              │
                              ▼
               [2차 AI 교차 검토 · crossCheck]  정답이 근거로 뒷받침되는가 · 정답이 하나뿐인가 · 안전한 표현인가
                              │
                              ▼
               통과한 문제만 출제 → 모자라면 기본 문제은행에서 겹치지 않게 채움
               (시간 초과·형식 오류·서버 꺼짐 → 기본 문제로 바로 진행, 아이 화면은 멈추지 않음)
```
- 검증 시험(일부러 틀린 문제를 섞은 시험용 응답): 지어낸 숫자("페트병 1개 = 나무 10그루")와 다른 마을 카드를 쓴 문제는 1차에서, 교차 검토가 부적합으로 판정한 문제는 2차에서 걸러졌습니다. 실제 모델로 돌릴 때도 걸러진 문제와 이유가 AI 활동 기록에 남습니다.
- 다시 설명 · 지구 숙제 · 얼음이 대답은 출제보다 가벼운 점검(안전 점검 + 근거 카드와의 관련성 + 근거 번호 대조)을 거칩니다. 점검에서 떨어지면 기본 설명·기본 카드를 보여 줍니다.

### 어린이 AI 안전장치 (js/safety.js)
- **개인정보 가리기**: 이름 · 전화번호 · 주소 · 아파트 동호수 · 학교 · 이메일 · 주민등록번호를 AI로 보내기 전에 ○○로 바꾸고, 아이에게 "비밀 지킴"을 알려 줍니다.
- **입력 살피기**: 욕설·폭력·성적인 말은 AI로 보내지 않고 부드럽게 돌려 말합니다. 스스로를 해치려는 말에는 곁의 어른과 1388에 알리도록 안내합니다.
- **답변 점검**: 링크·전화번호·금지어를 지우고, 너무 긴 답은 자릅니다. 근거 카드에 없는 내용의 질문은 AI를 부르지 않고 "얼음이가 가진 카드에는 없는 내용"이라고 답합니다.
- 로그인 없음 · 대화 저장 안 함 · 1.5초 안에 다시 묻기 제한.
- 규칙 기반이라 완벽하지 않습니다. 운영 시 기관 금칙어 목록을 함께 쓰세요.

## 3. AI 모델 연결 (모델 비종속)

앱은 `js/llm.js`의 `GreenLLM.chat()` 하나만 호출합니다(AI 환경비서의 연결 계층을 그대로 사용). **설정 화면에서 주소·모델명만 바꾸면 교체**됩니다.

| 연결 방식 | 쓸 수 있는 모델 예 |
|---|---|
| OpenAI 호환 (`/v1/chat/completions`) | Ollama·vLLM·LM Studio의 Gemma, EXAONE, Llama, GPT-OSS, Solar 등 / 행정안전부 AI 공통기반(OpenAI 호환 게이트웨이) / OpenAI / Google Gemini |
| Anthropic Messages | Claude |
| claude-artifact | claude.ai에 게시한 공개 시연 페이지 안에서만 (주소·키 불필요) |

설정 위치: 오른쪽 위 ⚙ → **AI 모델 연결** → 연결 테스트 → 저장하고 사용

### 무료 로컬 모델(Ollama)로 실행
1. https://ollama.com 에서 Ollama 설치
2. 모델 받기: `ollama pull gemma3:12b` (사양이 낮으면 `gemma3:4b`, 한국어 특화 `exaone3.5:7.8b`)
3. 브라우저 접근 허용 — Windows PowerShell:
   ```powershell
   setx OLLAMA_ORIGINS "*"
   ```
   설정 후 Ollama를 완전히 종료했다가 다시 켭니다. (macOS: `launchctl setenv OLLAMA_ORIGINS "*"`)
4. 앱 → ⚙ → 빠른 설정 `Ollama` → 연결 테스트 → 저장하고 사용

- 앱을 열 때 모델 서버가 응답하는지 먼저 확인합니다. 응답이 없으면 시작 화면에 "AI 연결 안 됨"으로 표시하고 기본 문제로 진행합니다.
- 작은 모델은 JSON 형식을 틀리기도 합니다. 이때는 그 회차만 기본 문제로 진행하고 AI 기록에 남깁니다. 교차 검토가 느리면 설정에서 끌 수 있습니다.

### 기관 배포 시 기본값
`js/config.js`에 기관 게이트웨이 주소·모델명을 적어 두면 아이들은 설정 없이 바로 씁니다. **API 키는 이 파일에 적지 마세요.**

## 4. 다른 주제로 바꿔 쓰기 (확산)

내용은 전부 `js/data.js` 한 파일에 있습니다. 화면·3D·AI 코드는 그대로 두고 이 파일만 바꾸면 다른 교육 주제가 됩니다.

| 대상 | 위치 |
|---|---|
| 마을 4곳 이름·친구·인사말 | `GQ_ZONES` |
| 근거 카드 38장 (AI가 쓸 수 있는 유일한 사실) | `GQ_CARDS` |
| 기본 문제은행 37문항 (학년 수준 1~3) | `GQ_BANK` |
| 기본 실천 카드 10장 | `GQ_ACTIONS` |

예: 물 절약 · 미세먼지 · 산불 예방 · 생활 안전 교육 자료를 근거 카드로 넣으면 같은 마을에서 그 주제 퀴즈가 나옵니다. 마을 건물 모양은 `js/world.js`의 마을 블록에서 바꿉니다.

```

js/world.js         3D 마을 (three.js) — 섬 · 아기 지구 · 온도계 · 4개 마을 · 친구들 · 얼음이 · 뭉게 · 나비

icon.svg            아이콘
```

## 6. 데이터 흐름 · 개인정보

- 로그인이 없고 이름·학교 같은 개인정보를 받지 않습니다. 진행 기록(도장·별·숙제·설정)은 **이 기기 브라우저(localStorage)에만** 저장됩니다.
- AI에게 보내는 것은 아이 질문(개인정보는 ○○로 가림) · 학년 · 근거 카드 · 문제 내용뿐이며, **설정한 모델 주소로만** 전송됩니다. 로컬 모델이면 PC 밖으로 나가지 않습니다.
- API 키는 기본적으로 브라우저 메모리에만 두며, '이 기기에 키 저장'을 켠 경우에만 저장됩니다.
- 수료증 이름은 인쇄용으로만 쓰고 어디에도 보내지 않습니다. 분석·추적 스크립트는 없습니다.

## 7. 알려진 제약

- 근거 카드·기본 문제는 공개 교육자료를 어린이 눈높이로 쉽게 고쳐 쓴 **체험용 예시**입니다. 실제 운영 전 환경교육 전문가·교사의 감수가 필요합니다.
- 읽어 주기는 브라우저 내장 음성(Web Speech API)을 써서 기기마다 목소리가 다르고, 한국어 음성이 없는 기기에서는 소리가 나지 않을 수 있습니다.
- three.js·글꼴을 CDN에서 받으므로 오프라인에서는 열리지 않습니다. 학교망에서 CDN이 막히면 three.js를 폴더에 내려받아 `index.html`의 importmap 주소만 바꾸면 됩니다.
- 안전장치는 규칙 기반이라 모든 표현을 잡지는 못합니다.
